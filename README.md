# Stock Metadata Studio

মাইক্রোস্টক প্ল্যাটফর্মের (Adobe Stock, Shutterstock, Vecteezy ইত্যাদি) জন্য ছবি থেকে
অটোমেটিক Title, Keywords আর Description তৈরির টুল। প্লেইন HTML/CSS/JS দিয়ে বানানো —
কোনো বিল্ড স্টেপ লাগে না, তাই যেকোনো ফ্রি স্ট্যাটিক হোস্টে সরাসরি আপলোড করা যায়।

## এটা কীভাবে কাজ করে (মাল্টি-প্রোভাইডার + অটো-ফলব্যাক)

আগের ভার্সনে একটা নির্দিষ্ট মডেলের নাম (`gemini-2.0-flash`) কোডে হার্ডকোড করা ছিল —
Google যখন সেই মডেল বন্ধ করে দিলো, অ্যাপ ভেঙে গেলো। এবার সেই সমস্যা পুরোপুরি
সমাধান করা হয়েছে:

- **তিনটা প্রোভাইডার সাপোর্ট করে:** Google Gemini, OpenRouter (একটা key দিয়ে
  অনেক প্রোভাইডারের ফ্রি ভিশন মডেল পাওয়া যায়), আর OpenAI (ঐচ্ছিক, পেইড)।
- **মডেল বাছাই সম্পূর্ণ স্বয়ংক্রিয়:** প্রতিবার জেনারেট করার সময় অ্যাপ নিজে থেকেই
  প্রতিটা প্রোভাইডারের কাছে জিজ্ঞেস করে "তোমার কাছে এখন কী কী মডেল আছে", তারপর
  সবচেয়ে ভালো ফিটটা বেছে নেয়। কোনো মডেলের নাম কোডে বসিয়ে রাখা হয়নি, তাই ভবিষ্যতে
  কোনো মডেল বন্ধ হয়ে গেলেও অ্যাপ নিজে থেকেই নতুন মডেলে সরে যাবে।
- **অটো-ফলব্যাক চেইন:** একটা মডেল ব্যর্থ হলে (বন্ধ হয়ে গেছে, quota শেষ, ইত্যাদি)
  একই প্রোভাইডারের পরের মডেল ট্রাই হয়; সেই প্রোভাইডারের সবগুলো ব্যর্থ হলে পরের
  প্রোভাইডারে চলে যায় (Gemini → OpenRouter → OpenAI)। যতগুলো key বসাবে, ততই
  reliability বাড়বে। একটাও কাজ না করলে তবেই "সমস্যা" দেখাবে, সাথে ঠিক কী কী ট্রাই
  হয়েছিল সেটার বিস্তারিত লগ।
- প্রতিটা ছবির নিচে ছোট করে দেখাবে কোন প্রোভাইডার আর মডেল দিয়ে সেটা তৈরি হয়েছে।
- ছবি আর সব key শুধু ইউজারের নিজের ব্রাউজারে (localStorage) থাকে, কোনো ব্যাকএন্ড নেই।

## API Key ফ্রি তে নেওয়া

**Gemini (প্রধান, ফ্রি):**
1. https://aistudio.google.com/app/apikey এ যাও (Google অ্যাকাউন্ট দিয়ে লগইন)
2. "Create API Key" চাপো, কপি করে অ্যাপে বসাও

**OpenRouter (ব্যাকআপ, ফ্রি — একটা key দিয়ে অনেক মডেল/প্রোভাইডার):**
1. https://openrouter.ai/keys এ যাও, সাইন আপ করো
2. একটা নতুন key বানাও, অ্যাপে বসাও
3. এই key দিয়ে অ্যাপ অটোমেটিক শুধু ফ্রি (`:free`) ভিশন-সাপোর্টেড মডেলগুলো খুঁজে নেবে

**OpenAI (ঐচ্ছিক, পেইড):** শুধু যদি আগে থেকে key থাকে আর extra reliability চাও,
তাহলেই দরকার — না দিলেও অ্যাপ পুরোপুরি চলবে।

দুইটা ফ্রি key-ই (Gemini + OpenRouter) বসিয়ে রাখা সবচেয়ে নিরাপদ — একটা বন্ধ/সীমা
ছাড়ালে অন্যটা অটো কাজ শুরু করবে। প্রতিটার নিজস্ব ফ্রি লিমিট আছে, যেটা সময়ে সময়ে
বদলাতে পারে — বদল হলেও অ্যাপ পাল্টানোর দরকার নেই, ও নিজেই মানিয়ে নেবে।

## ফ্রি হোস্টিং — Vercel

**ধাপ ১:** এই ফোল্ডার (index.html, style.css, script.js) নিয়ে GitHub-এ একটা নতুন
repo বানাও, ফাইলগুলো push করো।

**ধাপ ২:** https://vercel.com এ গিয়ে GitHub দিয়ে সাইন আপ করো (ফ্রি)।

**ধাপ ৩:** "Add New Project" → তোমার repo সিলেক্ট করো → Framework "Other" বা
"Static" রেখে দাও (কোনো build command লাগবে না, Vercel নিজেই static ফাইল সার্ভ করবে)
→ Deploy চাপো।

**ধাপ ৪:** কয়েক সেকেন্ডে একটা লাইভ লিংক পাবে (যেমন `your-app.vercel.app`), সেটা
সবার সাথে শেয়ার করা যাবে।

GitHub ছাড়াও চাইলে Vercel CLI দিয়ে সরাসরি ফোল্ডার থেকেও ডিপ্লয় করা যায়:
```
npm i -g vercel
cd metadata-tool
vercel --prod
```

## অন্যান্য ফ্রি অপশন

- **Netlify** — vercel-এর মতোই, ফোল্ডার ড্র্যাগ-ড্রপ করলেই ডিপ্লয় হয়ে যায়
  (https://app.netlify.com/drop)
- **Cloudflare Pages** — ফ্রি, ফাস্ট, GitHub কানেক্ট করে অটো-ডিপ্লয়
- **GitHub Pages** — একদম ফ্রি, তবে সেটআপ একটু বেশি ম্যানুয়াল

তিনটাই এই প্রজেক্টের জন্য সমান ভালো — কারণ পুরো অ্যাপটা static ফাইল, কোনো সার্ভার
কোড নেই।

### Google AI Studio সম্পর্কে একটা কথা

Google AI Studio (aistudio.google.com) মূলত prompt টেস্ট আর API key নেয়ার জায়গা,
এটা ওয়েবসাইট হোস্টিং সার্ভিস না। তবে ওখান থেকে "Build" ফিচার দিয়ে ছোট অ্যাপ বানিয়ে
Google-এর নিজস্ব ইনফ্রায় ডিপ্লয় করা যায় — সেটা এই কাস্টম UI-এর জন্য দরকার নেই,
Vercel/Netlify অনেক বেশি ফ্লেক্সিবল এই কেসে।
